# vk-cc-2026-sf
ВК КЧ 2026 - ПФ

Сырой файл лежит в `data/raw/`. Типизированные таблицы и сверки — в `data/interim/`. Те же строки с флагами качества — в `data/processed/`. Описание колонок: `data/interim/schema.yml` и `data/processed/schema.yml`. Пересборка из корня репозитория:

```bash
python -m vk_case
```

Команда читает xlsx, перезаписывает оба слоя и заново считает сверки. Ненулевой код возврата означает, что сверка чисел или числа флагов не сошлись.
