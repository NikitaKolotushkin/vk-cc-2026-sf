# vk-cc-2026-sf
ВК КЧ 2026 - ПФ

Сырой файл лежит в `data/raw/`. Типизированные таблицы и сверки — в `data/interim/`, описание колонок в `data/interim/schema.yml`. Пересборка из корня репозитория:

```bash
python -m vk_case
```

Команда читает xlsx, перезаписывает Parquet и заново считает `reconciliation.parquet`. Ненулевой код возврата означает, что сверка не сошлась. Слой `data/processed/` на этом шаге не заполняется.
