# Спеки

Читать по порядку.

1. `brief.md` — задание кейса.
2. `spec-ds-01.md` — паспорт данных.
3. `qa_session_notes.md` — что сказали на Q&A. Расшифровка: `sources/qa-2026-11-16.txt`.
4. `hypotheses_backlog.md` — все гипотезы, вердикты и трактовки. Карточки по одной лежат в `hypotheses/`.
5. `spec.md` — рамка решения.
6. `glossary.md` — термины кейса.
7. `miro_problem_framing.md` — короткая постановка для Miro. Полный текст: `miro_problem_framing_full.md`.

`hypotheses/00_preamble.md` и `hypotheses/90_matrices.md` — преамбула и матрицы, из которых собран бэклог. Копия карточки лежит рядом со скриптом проверки в `checks/H-01` … `checks/H-33`.
