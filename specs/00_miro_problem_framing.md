# Problem Definition Worksheet — короткая версия для Miro

Полный текст: `specs/04_miro_problem_framing_full.md`.

Цифры файла — синтетика. Доли 9 754 переносим на бизнес-сообщества. Абсолюты не есть отчётность VK. Таргета в задании нет.

## 1. SMART

Увеличить число товарных бизнесов, продающих через сообщество внутри ВКонтакте, и число оформленных там заказов. Эффект для VK считаем отдельно.

- **S:** сегмент, роль Маркета, путь, инструменты продвижения / продаж / работы с клиентами, плата за результат
- **M:** заказы через сообщество. База выборки: 298 сообществ, 3 478 заказов. Прокси: подключённые инструменты (чекаут 5 737 ≠ продажа). Выручка VK ≠ оформленный GMV: оплачено 1,2%. Таргет: `[после расчёта потенциала]`
- **A / R:** путь из уже существующих элементов. На пяти вопросах кейса
- **T:** сдача 22 ноября (бриф 09:00 / Q&A 23:59). Горизонт VK: год или несколько лет

## 2. Контекст

- VK: 93 млн MAU, 1 млн+ бизнес-сообществ. Контентная платформа
- С 2025 идут шопсы, автор × партнёр. На Q&A: ~140 тыс. заказов в день через авторский контент. Это не предмет кейса
- Предмет: предприниматель с сообществом. Инструментов много, цельного пути нет
- Обрыв: у активных товарных 91,7% без товара. Чекаут включён у 5 737, заказ есть у 298
- Товарный пост по охвату не слабее обычного. Слабее реакция
- Маркет мал: MAU 3 млн против 66,6 млн, видевших товар. Главная 0,2%. «Другое» 40% не расшифровано
- Деньги VK с бизнеса — реклама. 88% рекламных рублей выборки на сообществах без заказа

## 3. Критерии успеха

**VK и бизнес**

- Больше сообществ с заказом внутри, не больше включённых флагов
- Больше оформленных заказов. Оплата — отдельное число
- Выручка VK названа отдельно от GMV
- У каждого инструмента эффект для продавца и для VK
- Роль Маркета стыкуется с путём. Вход — не главная и не поиск

**Сдача**

- 5 вопросов по порядку. 8 слайдов. Эффект посчитан. Альтернативы на одних критериях. ИИ в приложении

## 4. In-Scope

- Товарные сообщества. Смежный тип на границе: 7,2% заказов
- Сообщество, посты и клипы, карточка, чекаут, доставка, оплата, сообщения, Маркет, реклама, аналитика
- Шопсы и AdBlogger рядом, не как объект кейса
- Внешний сайт как легитимный конец сделки
- Плата поверх рекламы. Комиссия не запрещена
- Место VK рядом с маркетплейсом, классифайдом и TikTok Shop

## 5. Out-of-Scope

- Услуги как стратегия: 0,1% заказов
- Кейс про шопсы для блогеров
- Новый маркетплейс со складами и ПВЗ
- Сохранять экран Маркета только потому, что он есть
- Называть оформленный GMV выручкой VK
- Складывать выборку и контуры. Подставлять готовую колонку среднего чека
- Называть «Другое» контентом. Считать ноль заказов продажей в переписке или на своём сайте
