## 3. Сегменты

### H-09. Заказы собраны в товарном типе, смежный тип проверяется по доле и по частоте

- **Название и домен:** тип бизнеса. Стратегия. Тип S.
- **Привязка к задаче кейса:** вопрос 2, кого берём. Услуги вне стратегии. Смежный тип нельзя ни выкинуть молча, ни развернуть в услуги.
- **Суть (H₁):** на тип `товарное` приходится ≥ 50% заказов чекаута, на `услужное` < 5% заказов, и смежный тип не перехватывает ядро. Ядро уезжает в смежный тип, только если его доля заказов ≥ 25% и его доля сообществ с заказом выше доли `товарное` не меньше чем на 5 п.п. Ядро уезжает в `без каталога`, если на этот тип приходится ≥ 25% заказов. **H₀** для ставки «целевой тип — товарное»: сработало одно из двух условий переноса ядра.
- **Данные:** `business_type`, `checkout_orders`, `checkout_gmv_rub`, `product_posts_30d`, `product_card_opens_from_content`, `checkout_enabled`, `goods_loaded`, `active_services`. Флаг `has_type_catalog_mismatch` не вычитается.
- **Метод:** F0. По каждому типу: число сообществ, доля с заказом, сумма заказов, сумма GMV. Рядом обязательная таблица из `H-08`: «без каталога» с товарными постами против «товарное» с чекаутом. `has_service_type_without_services` показывается как дыра определения услужного типа, не как сегмент. χ² и V Крамера — приложение, вердикт ставят доли и массы.
- **Конфаундеры:** тип не совпадает с каталогом. Маленькая доля сообществ может держать большую массу заказов, поэтому вердикт смотрит на оба числа. Услуги не становятся стратегией даже при доле заказов ≥ 5%: тогда в деке есть цифра, стратегии услуг нет.
- **Decision Impact:** H₁ устояла — кадр пути есть `товарное`, смежный тип остаётся карманом на схеме. Ядро перенесено в смежный тип — карман становится кадром, услуги всё равно не разворачиваются. Ядро перенесено в `без каталога` — `H-08` читается заново. На Q&A один сегмент разрешён, если он обоснован данными. Несколько сегментов не обязательны. Тип в файле — выбор админа при создании, не наша кластеризация. «Без каталога» может продавать постами и в сообщениях.
- **Приоритет:** P0.

- **Вердикт:** подтверждена
- **Трактовка:** Столбцы — какая доля всех заказов чекаута сидит на типе сообщества. Товарное держит 92,2%. Товарное и услужное 7,2%. Без каталога 0,5%. Услуги 0,1%. Доля сообществ, у которых вообще есть заказ, тоже выше у товарного: 7,7% против 0,1% у услуг. Целевой тип — товарное. Услуги и сообщества без каталога ядром не становятся.
