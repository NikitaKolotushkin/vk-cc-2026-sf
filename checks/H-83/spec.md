## 10. Добор по оставшимся колонкам

### H-83. Обычный пост в базе есть почти у всех, кто и так крупный

- **Название и домен:** обычные посты. Сообщества. Тип S.
- **Привязка к задаче кейса:** вопрос 5. Не назначить «начните постить» первым шагом там, где стена уже не пустая.
- **Суть (H₁):** В базе добора обычный пост есть не меньше чем у 70%, и разрыв доли с заказом ≥ 5 п.п. H₀: пост есть меньше чем у 70% или разрыв < 2 п.п.
- **Данные:** База добора: F0, тип «товарное», `active_goods > 0`, подписчиков больше 1 000. 1 292 сообщества, заказ у 186, заказов чекаута 3 082. `posts_30d`.
- **Метод:** Доля ненулевых постов. Две доли с заказом.
- **Конфаундеры:** Обычный пост не товарный. Товарный пост разобран в H-50.
- **Decision Impact:** Обе части устояли — обычный пост факт базы, а не недостающий шаг. Часть пала — молчание внутри базы ещё можно предлагать закрыть.
- **Приоритет:** P2

- **Вердикт:** подтверждена
- **Трактовка:** Обычный пост есть у 971 из 1 292, это 75,2%. С постом заказ у 16,1%, без поста у 9,3%. Разрыв 6,7 п.п. Заказов без обычного поста 101. Стена у этой базы в основном не пустая. Пустой остаётся товар на стене, не стена вообще.
