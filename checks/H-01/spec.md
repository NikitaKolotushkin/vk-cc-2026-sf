## 1. Контент и вовлечённость

### H-01. Товарный контент доходит хуже обычного на сопоставимой базе

- **Название и домен:** парное сравнение охвата и ER. Маркетинг. Тип S. Это H4, внутри ядра, не отдельная ставка.
- **Привязка к задаче кейса:** вопрос 3, барьер до карточки. Тезис Максима: товарный контент распространяется хуже обычного. Ориентир заказов здесь ещё не числитель: здесь причина, почему контент не доводит до сделки.
- **Суть (H₁):** на сопоставимой базе медиана отношения «товарная интенсивность / обычная интенсивность» ≤ 0,80. Отдельно и тем же правилом медиана отношения ER. Это два вердикта, не одно «или». **H₀** для каждого: медиана отношения в \[0,90; 1,10\]. Клетки решения: ниже только охват; ниже только ER; ниже оба; не ниже ни одно.
- **Данные:** `posts_30d`, `clips_30d`, `product_posts_30d`, `product_clips_30d`, просмотры, лайки и репосты обычные и товарные, `product_card_opens_from_content`. Флаги `has_product_posts_above_posts`, `has_engagement_above_views`.
- **Метод:** F0. Интенсивность = просмотры / (посты + клипы) своего контура. В пару охвата входят строки, где оба знаменателя > 0 и оба числителя просмотров > 0. ER = (лайки + репосты) / просмотры, оба просмотра > 0. Основное число — медиана попарного отношения. Знаковый тест и доля связок — приложение: квантование даёт много равных пар, и знаковый тест вердикт не подменяет. Из пары охвата исключить `has_product_posts_above_posts`. Из пары ER исключить `has_engagement_above_views`. На той же базе охвата отдельно показать медиану `product_card_opens_from_content / product_content_views`. С обычным контентом её не сравнивать: у обычного контента открытий карточки нет. Медиану товарных просмотров по всей таблице не использовать. F1 отдельно.
- **Конфаундеры:** просмотры обычного контента не помечены «за 30 дней». Лестницы квантования разные. Алгоритм ранжирования не наблюдается.
- **Decision Impact:** ниже охват при живом ER — барьер дистрибуции товарного поста. Ниже только ER — барьер качества контента. Оба порога не пройдены — тезис «товарный контент доходит хуже» на этой базе в деку не ставится. Эффект для VK в этой гипотезе один: больше товарных просмотров имеет смысл обещать только как шаг к заказу внутри, не как самоцель.
- **Приоритет:** P1.

- **Вердикт:** промежуточная
- **Трактовка:** График — два распределения. Для каждого сообщества, где есть и обычный, и товарный контент, взято отношение «товарное / обычное». Единица значит «одинаково». По просмотрам медиана 1,91 на 292 сообществах: товарный пост смотрят чаще обычного, тезис «доходит хуже» по охвату неверен. По реакции медиана 0 на 1 175 сообществах: лайков и репостов на товарный просмотр почти нет. На слайд можно ставить слабую реакцию, не плохую дистрибуцию.
