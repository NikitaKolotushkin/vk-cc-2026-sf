### H-03. Флаг автора не отбирает тех, кто продаёт внутри

- **Название и домен:** оценка модели. Маркетинг. Тип S.
- **Привязка к задаче кейса:** вопрос 2, не отсечь сегмент ошибочным флагом. Вопрос 3, не сделать флаг инструментом продвижения без связи с заказом.
- **Суть (H₁):** при `product_content_views > 0` доля заказов у `original_content_author = true` выше доли у `false` не меньше чем на 5 п.п. внутри корзин размера. **H₀:** разрыв долей < 2 п.п. Пустое значение — третья группа, не `false`.
- **Данные:** `original_content_author`, `checkout_orders`, `product_content_views`, `product_card_opens_from_content`, `subscribers`.
- **Метод:** F0, только положительные товарные просмотры. Основной исход — доля `checkout_orders > 0`, Манн–Уитни не нужен для доли: разница долей с интервалом Уилсона внутри корзин `H-11` и сводка по корзинам. Ноль заказов — наблюдение. «Непроверяема», если в группе true или false меньше 20 сообществ. Открытия на просмотр — второе число в приложении, вердикт по ним не ставится.
- **Конфаундеры:** флаг — оценка модели, пустых 2 570. Он может совпадать с темой и активностью. Заказ в переписке не виден.
- **Decision Impact:** H₁ устояла — флаг можно нести как ковариату, не как определение сегмента. H₀ устояла — путь и отбор продавцов через этот флаг не идут. Пустая группа похожа на true — флаг для отбора непригоден, пока оценка не заполнена.
- **Приоритет:** P2.

- **Вердикт:** подтверждена
- **Трактовка:** Столбцы — доля сообществ с заказом среди тех, у кого есть просмотры товарного контента. Авторы: 15,2% из 475. Не авторы: 10,9% из 680. Пустой флаг, 161 сообщество, на графике нет. Сырой разрыв 4,3 пункта, с поправкой на размер 5,3. Порог пройден впритык. Автора не берём как определение «кто продаёт»: в обеих группах заказа нет у большинства.
